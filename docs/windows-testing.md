# Windows 실사용 확인 절차

이 문서는 **절차서이자 기록 양식**이다. CI는 실제 Windows의 TSF 위에 가짜 응용 프로그램(창과 문서)을 세워 한글 타자를 확인할 뿐이며, 메모장·브라우저·메신저 같은 실제 응용 프로그램의 결과는 아래 표가 채워질 때까지 **없다**. 구현 범위와 한계는 [platforms.md](platforms.md)의 Windows 절과 [status.md](status.md)를 따른다.

## 설치

1. CI 실행의 아티팩트 `easime-windows-installer-<commit>`을 받아 압축을 풀고 `easime-<버전>-x64.msi`를 설치한다. 코드 서명이 없어 SmartScreen 경고가 뜰 수 있다.
2. 설치 창에서 "easime keyboard"가 켜져 있는지 본다. 설치가 끝나면 설정 → 시간 및 언어 → 언어 및 지역에 한국어와 키보드 `easime`가 있어야 한다(프로필은 하나이고 한국어 아래에 있다). 없으면 그 사실과 `%LOCALAPPDATA%\easime\easime.log`를 기록한다.
3. 작업 표시줄의 언어 표시 또는 Win+Space로 `easime`를 고른다.

## 입력 시험 (앱마다 한 번씩)

앱 후보: 메모장, 브라우저(Edge 또는 Chrome)의 입력창, 메신저, 워드패드 같은 서식 있는 편집기. 32비트 프로그램에서는 쓸 수 없는 것이 현재의 알려진 한계이므로 실패로 세지 않고 따로 적는다. 시험 중에 키를 잃는 경우를 찾으려면 환경 변수 `EASIME_LOG_KEYS=1`로 앱을 다시 시작해 `easime.log`에 모든 키가 남게 한다.

| 번호 | 절차 | 기대 | 확인할 점 |
|---|---|---|---|
| W1 | `gksrmf` | `한글` | 입력하는 중 마지막 음절이 계속 바뀌고, 글자가 사라지지 않는다. 조합 중인 음절에만 가는 밑줄이 보이고 확정된 `한`에는 없는지, 밑줄이 안 보이는 앱이 있는지 적는다(색은 앱이 정한다) |
| W2 | `gk` 후 Space | `하` 뒤에 공백 | 공백이 한 번만 들어간다(키 손실·중복) |
| W3 | `gk` 후 Enter | `하` 확정 뒤 줄바꿈 또는 전송 | 메신저에서 확정과 전송이 한 번의 Enter로 일어나는지 적는다 |
| W4 | `gk` 후 숫자 `1` | `하1` | |
| W5 | `gks` 후 Backspace 3번 | `한`→`하`→`ㅎ`→빈칸, 한 번 더 누르면 앞 글자를 지운다 | |
| W6 | 한/영 키(또는 오른쪽 Alt 탭)로 영어↔한국어 (일본어는 설정에서 켠 경우에만 순환에 있다: W14) | 영어에서는 `gk`가 그대로, 한국어에서는 `하` | 한/영 키를 누르고 있어도 한 번만 바뀐다. 전환 직후 커서 아래에 `A`/`한` 상자가 1초쯤 떴다 사라지는지, 어느 앱에서는 뜨지 않는지(자체 캐럿을 그리는 앱이면 뜨지 않는 것이 현재의 알려진 동작) 적는다 |
| W7 | 조합 중(`gk`)에 다른 창으로 이동했다 돌아오기 | `하`가 남는다 | 글자가 두 번 들어가거나 사라지지 않는다 |
| W8 | 조합 중 Ctrl+C, Ctrl+V | `하`가 확정된 뒤 복사·붙여넣기 | |
| W9 | 오른쪽 Alt 탭 뒤 메뉴 막대 | 전환되고, 메모장 같은 앱에서 메뉴 막대가 활성화되지 않는다 | Alt를 단축키로 쓰는 앱에서 Alt+키가 여전히 동작하는지 |
| W10 | 같은 PC의 다른 앱 두 개에서 모드 | 지금은 **앱마다 따로**다(알려진 한계) | 어느 앱이 어떤 모드로 시작하는지 적는다 |
| W11 | 한국어 모드에서 브라우저의 비밀번호 칸에 `gk`, 유튜브 페이지(입력칸 밖)에서 `k` | 비밀번호 칸에는 `gk`가 그대로, 유튜브는 재생/정지 | 앱이 그렇게 표시하지 않는 경우에는 한글이 조합될 수 있다. 어느 앱이 그런지 적는다 |
| W12 | 스토어 앱(Windows 설정 앱의 검색창, Microsoft Store 검색창)에서 easime로 전환해 `gksrmf` | `한글` | easime를 고를 수 있는지, 타자가 되는지, 모드 상자가 뜨는지 적는다. 이런 앱 안에서는 easime가 사용자 폴더의 설정을 읽지 못할 수 있어서, 설정 창에서 바꾼 언어·전환 키 대신 기본값으로 동작할 수 있다(2026-11-08 스토어 앱 범주 등록, 실제 동작은 미확인) |
| W13 | 한국어로 `gks`(한) 뒤 한자 키, 후보창에서 ↓·PgDn으로 움직이고 `1`~`9`나 Enter로 고르기, 다시 한자 키 뒤 Esc | 후보창이 커서 바로 아래에 뜨고, `>`와 배경이 선택한 후보에 있다. 숫자·Enter로 그 한자가 들어가고 창이 사라진다. Esc는 `한`으로 돌아간다 | 창이 엉뚱한 곳에 뜨거나 글꼴이 깨지는 앱, 큰 배율에서 크기, 창을 누르면 글이 확정되거나 포커스가 옮겨 가는지 적는다 |
| W14 | `%APPDATA%\easime\config.toml`에 `[languages]` `enabled = ["korean", "japanese"]`를 쓰고(설정 앱이 아직 없다) 몇 초 뒤, 한/영 키로 일본어(`あ`)로 가서 `nihon`, Space, Enter | `にほn`(점선) → Space로 후보창과 `日本`(굵은 밑줄) → Enter로 `日本`이 확정되고 Enter는 입력되지 않는다 | `kana`처럼 사전에 있는 다른 단어, ↓·PgDn·숫자 선택, Esc로 읽기로 돌아가기, 메신저에서 Enter가 전송까지 하지 않는지(DESIGN.md 4.2) 적는다 |
| W15 | 게임 안 채팅처럼 후보를 직접 그리는 전체 화면 게임에서 한국어 한자 변환이나 일본어 변환 | 게임이 자기 방식으로 후보를 보이고, easime의 후보창은 뜨지 않는다. 숫자·Enter로 고른 글자가 들어간다 | 게임 이름, 후보가 아예 보이지 않는지(그러면 고르지 못한다), 마우스로 고를 수 있는지(아직 지원하지 않음), 모드 상자가 뜨는지 적는다 |

## 제거

설정 → 앱에서 easime를 지운다(또는 `msiexec /x`). 한국어 언어와 `easime` 키보드가 목록에서 사라지고, 다른 언어 설정은 그대로여야 한다. 설치 프로그램은 easime를 쓰던 프로그램을 **닫지 않는다**(2026-11-08 결정). 바로 바꾸거나 지울 수 없는 파일은 다음 재시작 때 처리되고, 그때는 재시작이 필요하다고 알린다(설치 창은 사용 중인 프로그램 목록을 보이며 닫지 않고 계속할 수 있다). CI에서는 DLL을 불러 둔 프로그램을 띄운 채 무인 업그레이드·제거를 했고, 그 프로그램은 살아 있었으며 재시작 요청 없이 끝났다. 실제 PC에서는 메모장에 저장하지 않은 글을 둔 채 지워 보고, 메모장이 닫히지 않는지, 설치 창이 무엇을 묻는지, 재시작 뒤 `C:\Program Files\easime`가 사라졌는지 적는다.
