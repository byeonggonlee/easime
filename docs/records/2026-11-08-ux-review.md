## 기준과 판단

`main`의 `f9d8995`까지 최신화한 뒤, 이전 평가 이후의 설정·후보창·상태 표시·아이콘 변경을 검토했다.
[기준 CI](https://github.com/byeonggonlee/easime/actions/runs/42484925179)의 한국어 일반·언어, 일본어 모양 화면과 앱의 32px 아이콘을 직접 확인하고 관련 구현을 읽었다.
평가 기준은 [DESIGN.md](../../DESIGN.md)의 키보드 중심 조작, 상태 명확성, 동아시아 글자 가독성, 네이티브 일체감이다.
사용자가 직접 개선을 요청한 범위에서 기존 Kirigami 화면을 수정했다. 새로운 입력 방식이나 기본값을 정하지 않았다.

## 직관성: 바꾼 순서가 목록에서도 보여야 한다

기존 언어 목록은 항상 한국어→일본어 순서였다. 위·아래 버튼은 실제 전환 순서를 저장하지만 목록은 움직이지 않아, 사용자는 하단 요약문만 보고 결과를 추론해야 했다.
특히 일본어만 켠 뒤 한국어를 추가하면 실제 순서와 시각적 순서가 반대가 된다.

**수정**: 켠 언어를 실제 전환 순서대로 위에 놓고, 꺼진 언어는 그 아래에 둔다. 화면뿐 아니라 실제 자식 순서를 바꾸어 Tab 탐색 순서도 일치시킨다. 재배치 뒤 같은 언어의 조작 버튼으로 포커스를 복구하며, 더 이동할 수 없는 경계에서는 해당 언어 스위치로 복구한다.
화살표의 접근성 이름과 툴팁에는 대상 언어와 “전환 순서 앞으로/뒤로”라는 목적을 함께 넣었다. 키보드로 버튼에 포커스를 주어도 툴팁을 표시한다.
순환 시작의 영어와 설정 저장 방식은 그대로다.

## 직관성: 표시 시간은 체감하는 단위로

기존 모양 화면은 `1000`과 “밀리초 (1000 = 1초)”를 보여 주었다. 짧게/길게 표시하려는 사용자가 단위를 환산해야 하고, 동아시아 번역 화면에서도 설명이 불필요하게 길어진다.

**수정**: `1 초`처럼 초 단위로 표시·편집한다. 0.1~10초 범위와 0.1초 증감은 유지하며, 기존 파일의 1250ms 같은 값도 1.25초로 손실 없이 표현한다.
사용자 로케일의 소수 구분자를 읽고 표시한다. 네이티브 텍스트 입력과 줄이기·늘리기 버튼, 위·아래 키를 사용한다. 정수 SpinBox의 표시만 바꾸면 접근성 숫자 값에는 밀리초가 노출되므로, 보조 기술도 실제 초 단위 텍스트를 읽는 입력 컨트롤로 보완했다. 저장 파일은 계속 밀리초를 사용하며 저장 실패·외부 설정 다시 읽기 시 실제 저장 상태를 따르는 바인딩을 유지한다.
검증은 영문·독일어·한국어 숫자 로케일에서 경계값과 소수의 왕복 변환, 편집 후 외부 값 반영을 포함한다.

## GUI: 사용하지 않는 언어의 복구 안내가 주 화면을 차지한다

일반 화면 캡처에서 일본어가 꺼져 있는데도 사전 없음·재설치·검색 경로 안내가 길게 표시되어 화면 아래 내용이 밀렸다.
이 정보 자체는 필요하지만 한국어만 쓰는 사용자에게는 당장 해결해야 하는 오류처럼 보일 수 있다.

**수정**: 일본어 사전 상태는 일본어를 켠 경우에 표시한다. 지원 언어 정보와 언어 선택 경로는 계속 제공한다.
사전 검사·캐시·다시 읽기 기능은 유지한다. 오류를 감추는 대신 그 오류가 현재 입력에 영향을 주는 맥락에서 보여 주는 변경이다.

- `eae477d`: 긴 후보에 맞춘 폭 조절과 말줄임표는 무음 잘림보다 낫다. 유지한다. 다만 최대 폭을 넘는 후보의 전체 내용 확인, 작은 화면과 혼합 배율 검증은 남아 있다. 이번 수정으로 해결했다고 하지 않는다.
- `eeefb1a`, `6dcae89`: Windows의 명시적 전환에만 나타나는 상자, 포커스·수명·커서 위치 처리 개선은 방향이 맞다. 최신 상태를 예전 보고서의 “모드 표시 없음”과 혼동하지 않는다. 실제 Windows 앱과 배율별 시각 품질은 이번 Mac 환경에서 검증하지 않았다.
- `f9d8995`: 트레이 글자의 굵기·크기 확대와 앱 정체성 아이콘은 사용자 결정으로 기록되어 있으므로 유지한다. 32px 앱 아이콘에서는 작은 보조 글자와 궤도 구별이 제한적이다. 이는 실시간 모드를 나타내는 트레이와 별개인 앱 아이콘의 밀도 문제이며, 승인된 정체성 디자인을 이번 작업에서 임의로 교체하지 않는다.

## 검증과 남은 범위

CI 화면 조작 절차에 언어 두 개 활성화→역순 상태의 행 위치·포커스 체인 확인→순서 이동→실제 행 위치와 저장 순서 비교→한 언어 끄기를 추가했다.
표시 시간에는 로케일별 초 변환, 설정 저장, 편집 이후 바인딩 유지 검사를 추가했고 실패하면 CI가 실패하도록 했다.
다섯 표시 언어의 기존 캡처·조작 검사와 번역 누락 검사도 유지한다. 새 번역 역시 원어민 검토 전 초안이다.

새 시간 조작 검사가 한 처리 안에서 연속 저장을 실행하면서 Debian/Fedora 패키지 실행 검사에서 Kirigami 알림 객체의 `hovered` 조회 오류를 드러냈다. 같은 이벤트 처리 안의 성공 알림은 마지막 결과 하나로 모아 다음 이벤트 처리에서 표시하도록 보완했다. 기존 경고 검사와 연속 저장 검사를 유지하여 재발을 확인한다.

Mac에는 Qt/Kirigami 실행 환경이 없어 QML 실행과 수정 후 화면 확인은 main CI의 Fedora 결과로 확인한다.
실제 Plasma의 키보드 탐색·스크린 리더·확대 글씨·혼합 배율, 실제 Windows 앱은 여전히 별도 검증 대상이다.
이 문서는 모든 시각적 문제를 해결했다는 선언이 아니라 이번에 확인하고 수정한 범위의 기록이다.
