# easime 컨셉

easime(Easy Eastern Asian IME)는 한국어, 일본어, 중국어를 입력하는 입력기이자,
키보드만으로 쓰는 작은 생산성 도구 모음이다. Rust로 처음부터 만들며 ibus/fcitx에 의존하지 않는다.

## 누구를 위한 것인가
- **초보자도 쓸 수 있어야 한다.** 설치하고, 안내를 따라 하면 설정까지 끝낼 수 있어야 한다.
- 다만 Windows/macOS에서 기본 키보드를 벗어나지 못하는 진짜 초보보다는 **한 단계 위**를 대상으로 한다.
  즉 "한/영 전환과 설정 화면이 무엇인지는 아는" 사용자다.
- 그래서 첫 실행 안내, 쉬운 설정 화면, 문제가 생겼을 때의 되돌리기를 기능만큼 중요하게 다룬다.

## 어떻게 보이고 느껴져야 하는가
- **키보드가 주인공이다.** 마우스로 만질 화면은 적다: 상태 박스, 후보창, 팝업, 설정 앱 정도다.
- 화면이 적은 만큼 **미려해야 하고, 쓰는 데스크톱과 일체감**이 있어야 한다.
  - Plasma: Breeze 색, 시스템 글꼴, 강조색, 다크/라이트, 둥근 모서리, 화면 배율을 따른다.
  - Windows는 Fluent(WinUI 3), macOS는 SwiftUI의 시스템 스타일을 따른다.
- 입력을 방해하지 않는다: 포커스를 가져가지 않고, 잠깐 보였다가 사라진다.

## 기능
| 기능 | 설명 |
|---|---|
| 입력 | 한국어(두벌식), 일본어(로마자 → 가나 → 한자), 중국어(병음, 장기). 한 키로 영어 → 한국어 → 일본어 → … 순환 |
| 상태 표시 | 전환할 때와 입력창에 들어갈 때 커서 아래 `한`/`A`/`あ`/`中` 박스, 트레이 아이콘 |
| `Super + V` | 클립보드 기록 팝업. 최근 텍스트를 검색하고 골라서 붙여넣기 |
| `Super + .` | 이모지·카오모지·기호 팝업. 한국어/일본어/중국어 이름으로 검색, 최근 사용/즐겨찾기 |
| 설정 앱 | 각 OS에 맞는 네이티브 앱. 한 화면에서 언어, 전환 키, 백스페이스 단위, 모양을 바꾼다 |

## 결정한 것
- **단축키 충돌**: Plasma의 Klipper(`Meta+V`)와 이모지 선택기(`Meta+.`)가 이미 전역 단축키를 쓴다.
  easime가 이를 **대체**한다. 설정 앱/첫 실행 안내에서 한 번에 설정하고 **되돌리기 버튼을 반드시 둔다**.
  사용자의 설정을 바꾸는 일이므로 항상 확인을 받은 뒤 실행한다.
- **클립보드**: 텍스트만 기록한다(입력기로 붙여넣을 수 있는 것은 텍스트뿐이다).
  비밀번호 관리자에서 복사한 항목은 제외하고, 기본은 메모리에만 보관한다. 디스크 저장과 이미지 기록은 하지 않는다.
- **이모지 데이터**: Unicode CLDR(한/일/중 이름·검색어 포함)과, 라이선스를 확인한 카오모지 목록을 함께 배포한다.
- **팝업 UI**: 후보창과 같은 입력 패널에 직접 렌더링한다. 키 입력은 입력기가 처리하므로 검색어를 칠 수 있다.
  시스템 색상 연동은 직접 구현하고, 완성도를 본 뒤 Kirigami 전환 여부를 다시 검토한다.

## 기술적으로 확인된 것 (KDE Plasma 6.8, Wayland)
- KWin이 `ext_data_control_manager_v1`을 제공해서 **포커스 없이도 클립보드 변화를 감시**할 수 있다.
- 입력기로 삽입할 수 있는 것은 텍스트(`commit_string`)뿐이다.
- 전역 단축키는 입력기보다 KWin이 먼저 처리한다. 그래서 위의 "대체" 설정이 필요하다.
- 입력 패널은 KWin에 **창이 하나뿐**이라 상태 박스, 후보창, 클립보드/이모지 팝업이 한 번에 하나씩 번갈아 쓴다.
