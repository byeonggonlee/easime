# Windows 실사용 확인 절차

이 문서는 **절차서이자 기록 양식**이다. CI는 실제 Windows의 TSF와 Windows Installer 위에 가짜 응용 프로그램(창과 문서)을 세워 한글·일본어 타자, 설치·업그레이드·제거, 설정 앱 열기를 확인할 뿐이며, 메모장·브라우저·메신저·게임 같은 실제 응용 프로그램과 실제 PC의 결과는 아래 표에 적힌 것뿐이다. 2026-11-09에 W1–W14가 문제 없이 통과했다고 보고되었다(상세는 표). W15–W18은 아직 시험하지 않았다. 구현 범위와 한계는 [Windows 구현 현황](../implementation/windows.md), 전체 현황은 [status.md](../status.md)를 따른다.

**이 시험의 결과로 정할 것**: Windows 설정에서 easime를 어느 언어 아래에 보일지([decisions.md](../decisions.md) "Windows 등록 방식")는 실제 PC 시험 뒤에 다시 정하기로 했다. 그래서 설치 후 **설정 → 시간 및 언어 → 언어 및 지역에서 easime가 어디에 어떻게 보이는지**, **작업 표시줄의 언어 표시가 무엇인지**(한국어로 남는지), W12(스토어 앱)의 결과를 꼭 적는다.

## 설치

1. CI 실행의 아티팩트 `easime-windows-installer-<commit>`을 받아 압축을 풀고 `easime-setup-<버전>-x64.exe`를 실행한다(MSI만 설치하려면 `easime-<버전>-x64.msi`). 코드 서명이 없어 SmartScreen 경고가 뜰 수 있다. Windows App Runtime이 없는 PC에서는 `setup.exe`가 Microsoft에서 설치 파일(약 116MB)을 받아 먼저 설치하므로 인터넷이 필요하다(W17).
2. 설치 창에서 "easime keyboard"가 켜져 있는지 본다. 설치가 끝나면 설정 → 시간 및 언어 → 언어 및 지역에 한국어와 키보드 `easime`가 있어야 한다(프로필은 하나이고 한국어 아래에 있다). 없으면 그 사실과 `%LOCALAPPDATA%\easime\easime.log`를 기록한다. 시작 메뉴에 "easime"(설정 앱)가 있어야 한다.
3. 작업 표시줄의 언어 표시 또는 Win+Space로 `easime`를 고른다.

## 입력 시험 (앱마다 한 번씩)

앱 후보: 메모장, 브라우저(Edge 또는 Chrome)의 입력창, 메신저, 워드패드 같은 서식 있는 편집기. 32비트 프로그램에서는 쓸 수 없는 것이 현재의 알려진 한계이므로 실패로 세지 않고 따로 적는다. 시험 중에 키를 잃는 경우를 찾으려면 환경 변수 `EASIME_LOG_KEYS=1`로 앱을 다시 시작해 `easime.log`에 모든 키가 남게 한다.

| W10 | 같은 PC의 다른 앱 두 개에서 모드 | 지금은 **앱마다 따로**다(알려진 한계) | 어느 앱이 어떤 모드로 시작하는지 적는다 |
| W11 | 한국어 모드에서 브라우저의 비밀번호 칸에 `gk`, 유튜브 페이지(입력칸 밖)에서 `k` | 비밀번호 칸에는 `gk`가 그대로, 유튜브는 재생/정지 | 앱이 그렇게 표시하지 않는 경우에는 한글이 조합될 수 있다. 어느 앱이 그런지 적는다 |
| W12 | 스토어 앱(Windows 설정 앱의 검색창, Microsoft Store 검색창)에서 easime로 전환해 `gksrmf` | `한글` | easime를 고를 수 있는지, 타자가 되는지, 모드 상자가 뜨는지 적는다. 이런 앱 안에서는 easime가 사용자 폴더의 설정을 읽지 못할 수 있어서, 설정 창에서 바꾼 언어·전환 키 대신 기본값으로 동작할 수 있다(2026-11-08 스토어 앱 범주 등록, 실제 동작은 미확인) |

| W14 | 설정 앱(시작 메뉴 "easime")의 언어 페이지에서 日本語를 켜고(또는 `%APPDATA%\easime\config.toml`에 `[languages]` `enabled = ["korean", "japanese"]`를 쓰고) 몇 초 뒤, 한/영 키로 일본어(`あ`)로 가서 `nihon`, Space, Enter | `にほn`(점선) → Space로 후보창과 `日本`(굵은 밑줄) → Enter로 `日本`이 확정되고 Enter는 입력되지 않는다 | `kana`처럼 사전에 있는 다른 단어, ↓·PgDn·숫자 선택, Esc로 읽기로 돌아가기, 메신저에서 Enter가 전송까지 하지 않는지(DESIGN.md 4.2) 적는다 |

| W16 | 시작 메뉴의 "easime"로 설정 앱을 열고, 언어 페이지에서 日本語를 켜고 끄기, 단축키 페이지에서 전환 키 바꾸기. 시스템 언어를 바꾸거나 `--ui-language=ja`로 다른 표시 언어 확인 | 창이 열리고 페이지(일반·언어·단축키·한국어·모양)가 보이며, 바꾼 값이 설정 파일에 저장되고 **다시 시작하지 않아도 몇 초 뒤 입력에 반영된다** | 키보드만으로 모든 페이지에 갈 수 있는지, 스크린 리더가 컨트롤 이름과 값을 읽는지, 고대비·큰 글씨·배율에서 잘리는 글자가 있는지, 라이트·다크 테마에서 Mica 배경이 읽히는지, 번역이 어색한 곳(한국어 외는 초안)을 적는다. 일반 페이지에 사전 상태가 "있음"인지도 적는다 |
| W17 | Windows App Runtime이 없는 PC(새로 설치한 Windows 또는 가상 머신)에서 `setup.exe` 실행. 한 번은 인터넷을 끊고도 실행 | 런타임 설치가 먼저 진행된 뒤 easime가 설치되고 설정 앱이 열린다. 인터넷이 없으면 무엇이 일어나는지 기록한다. 런타임이 없는 PC를 만들기 어려우면 Windows Sandbox나 새 가상 머신을 쓴다(Sandbox는 Windows 11 Pro 이상) | 설치 창의 모양과 진행 표시, 다운로드에 걸린 시간(느린 회선), 설치 후 앱 목록에 easime가 하나만 보이는지, 제거하면 easime만 사라지고 런타임은 남는지 |
| W18 | 메모장에 저장하지 않은 글을 둔 채(easime로 입력 중이었던 프로그램) easime를 제거하거나 새 버전으로 업그레이드 | 메모장이 닫히지 않고 글이 남는다. 설치 창이 사용 중인 프로그램을 보이되 닫지 않고 계속할 수 있다. 재시작이 필요하다고 알린다 | 설치 창이 정확히 무엇을 묻는지, 재시작 뒤 `C:\Program Files\easime`가 사라졌는지, 업그레이드 뒤 새 DLL이 새로 연 프로그램에서만 쓰이는지 |

## 제거

설정 → 앱에서 easime를 지운다(또는 `msiexec /x`). 한국어 언어와 `easime` 키보드가 목록에서 사라지고, 다른 언어 설정은 그대로여야 한다. 설치 프로그램은 easime를 쓰던 프로그램을 **닫지 않는다**(2026-11-08 결정). 바로 바꾸거나 지울 수 없는 파일은 다음 재시작 때 처리되고, 그때는 재시작이 필요하다고 알린다. 사용 중인 프로그램을 둔 시험은 W18이다. CI에서는 DLL을 불러 둔 프로그램을 띄운 채 무인 업그레이드·제거를 했고, 그 프로그램은 살아 있었으며 재시작 요청 없이 끝났다(쓰던 DLL은 `C:\Config.Msi`로 옮겨져 다음 재시작 때 지워진다). 제거하면 설정 앱과 시작 메뉴 항목도 사라지고, Windows App Runtime은 남는다.
